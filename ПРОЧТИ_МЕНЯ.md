# Накшатра Луны

Маленькое офлайн-приложение: считает **только накшатру Луны** в традиции джйотиш
(ведическая/сидерическая система, аянамша **Лахири**) на **швейцарских эфемеридах**.
Ничего лишнего — одно поле места, дата, время и результат.

## Что внутри особенного

- **Офлайн-поиск места — вся Россия, включая сёла и деревни** (≈203 000 населённых
  пунктов из GeoNames, в т.ч. заброшенные и исторические) + крупные города мира
  (≈66 000). Поиск по-русски: даже у деревень без русского имени в GeoNames оно
  получено транслитерацией латиница→кириллица. Одноимённые деревни различаются
  по **району и области**. Выбор места автоматически подставляет часовой пояс.
- **Исторический часовой пояс.** Берётся то смещение UTC, которое **реально
  действовало в дату рождения**: декретное время (+1 ч с 1930), летнее время
  1981–2010, «вечное лето» 2011, отмена перевода в 2014 и региональные изменения.
  Данные — IANA tz database через moment-timezone (офлайн, с полной историей).
- Луна считается **геоцентрически**, поэтому накшатра зависит от даты, времени и
  часового пояса, **но не от координат** — место нужно по сути для определения пояса.

## Запуск

Это папка (из-за WASM-эфемерид), а не один HTML. Нужен локальный сервер:

```
python3 -m http.server 7904 --directory ~/jyotish-nakshatra
```

или конфигурация **jyotish-nakshatra** в `~/.claude/launch.json` (порт 7904).
Открыть: http://localhost:7904/ . Если открыть файлом (file://), поиск города и
WASM не загрузятся — тогда работает приближённый расчёт Луны и ручной выбор пояса.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | приложение (форма, поиск, движок, расчёт) |
| `swisseph.{js,wasm}`, `swisseph-browser.js` | Swiss Ephemeris (WASM, режим Moshier) — из «Камней»/«Сюиты» |
| `vendor/moment*.js` | исторические часовые пояса (moment-timezone с полной базой) |
| `astro-app.css` | дизайн-система goroskop1008 (шрифт Jaipur) |
| `data/cities.txt.gz` | сжатая база мест (≈3.5 МБ; грузится через DecompressionStream) |
| `data/cities-meta.json` | список зон и админ-меток (регион/район/страна) |
| `build/build_cities.py` | как пересобрать базу из дампов GeoNames |
| `LICENSE.swisseph.txt` | лицензия Swiss Ephemeris |

## Пересборка базы мест

Скачать дампы GeoNames (`RU.zip`, `cities5000.zip`, `alternatenames/RU.zip`,
`admin1CodesASCII.txt`, `countryInfo.txt`) в одну папку, прописать путь `SP` в
`build/build_cities.py` и запустить `python3 build/build_cities.py`.
